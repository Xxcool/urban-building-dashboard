# v23 景观制作规格与相机构图门槛

事实源：planning/project.json → production.landscape；不在文档再维护坐标副本。确认见 campus-landscape-approval-v23.md。

沿用园区400×320m、8栋布局与现有campus/building相机。中央原圆形节点内布置浅水池，外围环行铺装保留主步行通路；横向与纵向步道在池边截断并接入广场环带，不穿水。廊架两组，净高3.2m以上；座椅12组，另有水景边坐凳。A1入口雨棚、台阶与坡道，14片种植床、20名米制人物与6辆自行车，均为展示装饰，不新增业务指标或拾取身份。

先生成landscape-layout独立目录，浏览器在1920×1080验证：水景居中但不遮挡C1/C2，廊架两组可辨，所有楼宇标签仍可读，A1入口靠近真实裙房前沿，步道连续且不穿水/建筑。布局简模通过后再生成细节。两组廊架拟用23/25m长格栅形成总览可见轮廓，尺寸属于制作估计；屋面轻薄、长向与步行轴线相随。

静态景观按材质合批，复用既有叶簇和木石颜色；水面与低涌泉在统一可见时钟驱动，无额外rAF，隐藏与后台停步。新增上限4.5万三角形、5MB模型、30绘制调用；页面总预算继续按原配置实测，不以GLB体积代替帧时间。

未确认模型压缩方案，本轮不混入几何压缩/贴图转码。生成阶段锁定概念输入哈希、模型及配置哈希、脚本模块哈希。最终保留概念/实际并排、三层截图、卡片拾取、动画与往返资源检查及独立重建记录。
