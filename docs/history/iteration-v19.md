# v19：城市复核、入场动效与逐栋演示指标

## 授权与复用

业务范围沿用武汉光谷背景、虚构示范园区，招商及领导汇报，城市→园区→重点楼宇，浅色B方案和全窗口适配。没有重做调研或检索完整大屏案例。

用户确认：“动画效果按照方案执行，然后‘AI’是指‘A1 科创大厦’，设计图中圈选区域底部湖泊在里面的，你现在把湖泊分割了。”随后指出线粗/外晕少、楼宇与湖泊不自然，以及点击楼宇缺少经营指标和左侧选中信息，并要求“继续会话任务”。以上为本轮实施依据，不等于用户已批准本轮成品。

原城市、园区、楼宇概念确认继续有效，图片未修改；原始决定与哈希保留在state.json历史。正常与无数据整屏基准继续复用，新增卡片与动效属于既定方向的交互扩展。

## 实现

- 单一3.2秒入场时间线：城市材质展开、边界按弧长描绘、金色园区定位环、点位及面板依次进入。完整段仅首次及主动“重播入场”播放；返回城市只作0.45秒淡入。操作打断时结束时间线并保留当前镜头，导航、复位和减少动态效果有明确终态。
- 8栋演示指标来自planning/project.json；A1原快照保持。园区运行汇总只由逐栋指标派生，原campus总量作为生成校验约束。合计24万㎡、可租20万㎡、已租16.8万㎡、216家，整体出租率84%。其他楼宇不聚焦，左右读取同一selectedId与快照；A1可下钻。
- 左栏去掉空间方位、身份说明和强制跳转A1文案。信息卡避让标签和底部导航，可关闭及Escape退出。无数据模式统一用空值，不把缺失变成零。
- 底部改回设计稿中的两片独立湖泊，平滑湖岸全部包含在圈选区域内。建筑检查整栋岸线缓冲，增加屋顶退台/设备/立面层次；植被改用实体低面数树冠，增加湖岸公园和林带；水面使用按岸线距离生成的顶点色及微波反射。
- 蓝线变细，实体线身与柔和外晕分开，Bloom合成只取模糊结果，避免把原始高亮再次叠加冲白。
- 林带增加后记录到帧耗时上升；AO独立降低分辨率，入场进度直接更新两项展示变量，避免每帧重绘整屏Vue树。主画面输出分辨率保持。

## 核验与限制

7项Node测试覆盖逐栋汇总、缺失状态、坐标、车辆路线、动效顺序/返回/减少动态效果、两湖平滑岸线包含。实际浏览器覆盖七栋切换、左右指标同步、C1无数据、A1下钻、重播与返回，并记录资源数及帧耗时。新目录完整生成GLB、runtime、依赖安装、测试、构建、资产校验；实际日志见checks/rebuild-v19-final.json。

检查与图片对照见checks/review-v19.html、checks/runtime-v19.json。树冠与街区结构已有变化，但道路层级、建筑个体和湖岸景观仍比原AI稿简化，R-05-REALISM继续开放。性能只记录本机浏览器样本，不代表目标大屏硬件或长时认证；未修改系统设置实测减少动态效果，仅有逻辑测试。
