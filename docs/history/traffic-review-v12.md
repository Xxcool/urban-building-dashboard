# 车辆动画修复 v12

原车体合并在静态环境，已改为独立Blender模板和3个共享材质实例批次。18辆车按道路宽度与园区尺度派生双向闭合车道，以8m/s行驶，圆弧转弯，首尾连续；切层保持同一时钟。后台visibility事件清除上一帧时间，最大步长0.1秒，避免恢复时大幅跳位。属于装饰示范交通，不产生经营或实时交通统计。

3项Node测试通过（含道路/连续性/闭环/双向间距），生产构建和模型契约通过。实际网页采集了首车13.849/34.283/58.032秒的位置，朝向从0转为π/2；4轮园区/楼宇切换时钟持续，见checks/traffic-runtime-v12.json。1920×1080观测156 draw calls、96几何、17纹理，帧间隔P95约17.4ms；仅本次环境短时结果，原12轮v11结果不是v12性能认证。

初次验证发现4174服务混用旧运行配置，保留日志；已将当前页切换到4175的app/dist独立服务，当前地址日志无新错误。初次从源重建发生在当前模型同步前，旧比较记录为different；随后重新执行rebuild-v12-final.json为passed，GLB和runtime哈希一致，不覆盖失败记录。

制作规格见production-spec-v12-traffic.md；两层截图与AI基准见checks/comparison-v12.html。建筑形体、相机与业务内容保持；原v11的远景和材料表现限制继续适用。截图代表运动的单一时刻，运动由时间采样和路线测试验证。
