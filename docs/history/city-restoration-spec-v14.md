# v14 按用户反馈重开城市还原

用户明确指出v13城市未铺满、可见矩形地图、区域边界不发光、示范分区无色、湖泊与楼宇缺少真实感。本轮沿用已确认B-city-v1及其无数据稿，不修改基准，不重做概念或检索案例；以实际截图逐条复验。v13属于视觉未通过，先前工程检查不能替代还原验收。

唯一空间事实源仍为planning/project.json。production.city.alignment记录确认图1672×941地面控制点，city_layout.py将区域轮廓、湖岸、分区和园区反投影到制作相机的平面；原始控制点只表达概念图估计，不能推出真实边界、坐标或建筑高度。模块哈希锁在规划内，模型与runtime共用派生函数，校验器读取真实GLB节点坐标。

构图：城市地面24km背景延伸到相机边界之外；区域轮廓占右侧场景约94.5%宽、74.3%高，不以一块有限底板承载城市。位置对照以地面控制点为准；楼宇高度从既有制作估计延续，不能从图硬算高度。示范园区在区域LOD放大1.35以保证可识别，明确是概念尺度变形，详细园区尺寸保持。

样式：区域Green/Cyan/Gold三个地面色区、金色示范片区与白青双层发光线；光晕先在灰盒中验证，a版过曝和水面干涉保留，b版收敛Bloom与相机near至20m后复验。边界不做光墙，不以辉光遮挡结构。

深化：自然样条岸线、浅岸/深水与岛屿、曲线主干路和较细街道、成组沿街建筑、混合条板/裙房/塔楼、复用固定透明叶簇和程序化微波法线/日光反射。仍是实时代码和模型，不使用整张AI图作为场景贴图。

规模预算随连续城市范围和真实感要求调整为15MB/38万三角形/130绘制调用，必须测量，不以放宽数字掩盖未验证性能。灰盒v14b已实际检查：矩形边缘消失，湖岸/分区/边界投影对齐；细化后再测透明树叶与Bloom成本。
