# 园区进入动效提案 v22（原提案，后续已确认）

触发：用户本轮要求“进入园区缺少动画效果，设计一下”。保留浅色B方案、城市→园区→A1的范围。现状是App直接切换level和active，首次园区需载入校园GLB；已有3.2秒城市首次入场与A1镜头过渡，不等于园区入场动画。

## 视觉分镜：推荐首次约2.8秒

| 时间 | 画面 |
|---|---|
| 0–0.25秒 | 园区金色定位点轻亮一次，园区边界加深；产业/配套浮层收起，非目标标签淡出。标题与层级导航保留。 |
| 0.25–1.25秒 | 城市镜头平滑向示范园区靠近，目标保持在主场景视觉中心，外围城市逐渐退为背景。左侧区域内容轻淡出。 |
| 1.05–1.65秒 | 在一致的园区位置与投影视角上，从城市简化园区交接到详细园区，短时交叠约0.4秒；保留地面定位关系。 |
| 1.45–2.3秒 | 镜头缓慢落到确认的园区默认斜俯视角；地面道路先清晰，建筑材质逐渐完整，保持各楼真实相对高度与比例。 |
| 2.1–2.8秒 | A1标识先出现，其余楼宇标签分两组轻淡入，左侧园区指标逐项显现。车辆继续共用仿真时钟行驶，镜头停稳后恢复自由操作。 |

整体使用柔和减速曲线，动作重叠，视觉重点是园区被选中和空间层级自然接续。次次返回不重播整套：从A1返回园区约0.6秒镜头拉回；从城市再次进入园区约1.1秒简化过渡。直接点顶部“园区总览”与场景园区入口走同一条进入路径。

## 制作边界与实现前置

城市园区与详细园区共用楼栋规划坐标，城市根节点位于city.campusPositionM、比例为1.35；交接相机和target可按(C−campusOrigin)/campusScale转换，再缓动至production.cameras.campus，接续同一fov后再过渡到默认32°，避免两套模型任意缩放造成跳镜。

进入时先准备详细园区资源，准备期间保持城市园区镜头；仅资源可用才进行交接。首次载入超出预期时，在已靠近的园区位置短暂停留并显示轻量进入状态；失败留在城市并提供重试。不能出现空白canvas或未绑定标签。正式实施前先用当前模型验证切换关键帧的投影一致，再做材质与UI渐入。

点击其他导航取消当前进入并进入用户所选层级；拖动或滚轮在交接前取消并留在城市、交接后中止导演镜头并留在园区，保持当前可用镜头。尊重系统减弱动效，采用约0.15秒淡入。标签只有可交互时才启用，避免半透明阶段误触。后台返回不累积dt；帧时间、连续点击与返回至少做12轮验证。

本提案没有改动规划源或替用户确认。确认后将动效时间线写入唯一规划入口，并更新App/两层场景统一过渡状态，不新增第二份业务指标或URL状态。

用户在此分镜展示后回复“可以”，本轮据此实现。当前实现与验证见docs/iteration-v22.md；上文保留提案时的现状与前置说明，不代表当前仍未编码。
