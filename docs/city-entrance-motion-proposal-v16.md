# 城市入场动效提案 v16（待用户确认）

沿用已确认浅色B方案与v15全窗口布局，不更换模型、布局或终态相机。本轮只设计入场编排；不将动效视为城市真实性问题R-05-REALISM的修复。

## 观感与时序

资源完成加载且可见的首帧开始计时，总长约3.2秒；资源下载不纳入动画时长，不用动画伪装加载进度。

| 时间 | 场景 | 信息与焦点 |
| --- | --- | --- |
| 0–0.6秒 | 湖面与地形柔和显现，城市以浅色低对比轮廓出现；相机从略远约6%的位置平缓靠近 | 标题与层级导航先可用，其他内容轻淡入 |
| 0.4–1.6秒 | 建筑、路网、植被恢复完整材质与阴影，保持真实几何比例 | 各模块按阅读顺序渐显，轻微位移不超过12设计像素 |
| 0.9–2.3秒 | 青白光头沿现有区域边界走完一圈，留下稳定轮廓；尾迹柔和而非整条同时闪烁 | 区域填色淡入，扫描只表达示意区域被识别，不代表真实业务操作 |
| 2.0–2.8秒 | 示范园区金色区域由淡到清晰，出现一次定位扩散环 | 园区标记由下向上约10设计像素进入，随后出现其他点位 |
| 2.6–3.2秒 | 相机准确到达原终态，轮廓收敛为既有常亮效果 | 面板完成显现，进入正常交互 |

保持浅色建筑展陈风格，不加爆闪、强烈镜头旋转或反复扫描。数据保持实际演示快照，不做从零滚动以免制造实时变化假象。

## 交互与生命周期

- 完整入场仅在本次页面首次进入城市时播放。返回城市用约0.45秒淡入，保留正常返回语义。
- 拖拽、缩放或点击导航立即结束入场；拖拽从当前镜头接管，不能随后被时间线拉回。切换层级则结束并清理临时效果。
- 复位只恢复原镜头，不强制重播。设置增加“重播入场”，供汇报演示主动使用。
- 系统减少动态效果时直接呈现终态，可保留不超过0.2秒的淡入；后台不推进可见动画时钟，恢复时无大dt跳变。
- 加载失败沿用现有失败提示；加载完成前不启动描边和园区定位。

## 现状核对与实施边界

CityView已有完整城市模型、基于spec.outline生成的三层TubeGeometry边界、独立Bloom、区域材质、点位DOM投影、OrbitControls与rAF；当前全部在加载后直接出现。描边应沿同一边界曲线按弧长揭示，保持三层光晕对齐，不能再手工维护另一条边界。

由单一入场进度派生相机、材质呈现、描边、标签和UI状态。动效配置进入planning/project.json并由已有生成流程输出到runtime；不新增URL、缓存或第二套业务统计。材质共享、透明深度、阴影/Bloom层与GTAO需分别验证，避免淡入导致树卡片或建筑穿透。临时光头、扩散环必须在完成和卸载后停止并释放，不增加持续后处理管线。

## 验证计划

冻结原终态基准，保存0.4、1.3、2.2和3.2秒实际网页阶段截图与终态对照；检查2048×951及1920×1080。实际操作验证入场中拖拽/导航打断、返回城市、主动重播、后台恢复和减少动态效果；比较播放前后资源数量及帧耗时。最终镜头与原默认相机一致，不用一次截图替代动效验证。
