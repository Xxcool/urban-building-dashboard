## 建议实施顺序

1. 接通并验证 Blender MCP：读取场景、执行规划驱动的 Python、获取相机渲染、保存工程；实际核对输出文件。MCP 作为制作与检查入口，生成脚本和规划源继续保留，确保可重建。
2. 按终稿补齐城市、园区、楼宇制作规格，先校准相机、体量、湖岸、道路、楼宇位置，再深化材质与细节。不得用烘焙掩盖几何与构图差异。
3. 先以园区 A1、裙房及相邻广场作试验片区：UV2 与留白、Cycles AO 和间接光分开烘焙，验证网页材质接入与实际收益，再扩展到其他静态对象。
4. 烘焙覆盖静态地面、建筑接触面、廊架等固定设施；车辆、行人、喷泉水体、选中高亮与动态状态保持独立。玻璃保持实时反射，不把整幅效果图贴到模型上。
5. 网页使用独立 AO/光照输入；避免 AO、间接光、实时阴影重复叠加。由试验片区决定贴图分辨率、拆包、加载和压缩预算，不先给整座城市统一大贴图。
6. 每层固定相机、画布、灯光和数据，保存终稿与网页截图对照；核对接缝、色彩、遮挡、拾取、加载大小与帧时间。质量与性能未通过时不替换当前可用资产。
