# 区域层整屏设计与三层衔接

正常态复用用户确认B-city-v1（完整UI与场景）；无数据态使用自动生成city-no-data-design-v1.png，生成提示词及记录保留。两张均为AI视觉稿，不用代码拼稿替代。

1920×1080画布，左28%暖白信息栏，右72%区域场景。信息栏含标题/区域演示标识、区域名称、产业方向、重点园区卡片。四项指标只读取既有demoDesign.campus，不建立重复数值。AI图数量旁文字排版以整屏实现的“楼宇数/建筑面积/出租率/入驻企业”纠正，不从AI文字生成事实。产业方向是已知定位，经营无数据时仍保留；园区卡片数字显示—，出现“暂无园区经营数据”，进入按钮继续可用。

默认进入区域，点园区地块/入口→园区；点A1→楼宇；楼宇返回→园区，园区返回→区域。三层导航允许直接进入已知对象，A1选择在返回时恢复，数据模式全程保持。区域其他两处标签只提供空间示意，不虚构详情与统计。Esc逐层返回，Home复位当前相机。

区域为独立简化LOD资产，园区/楼宇继续复用同一详细GLB，避免把概念城市场景当真实模型。已访问的场景保留实例，隐藏时停止绘制并重置时间，返回后车辆不中断累计的演示进度且不累积后台dt。区域与园区都是演示资料；页脚必须显示非测绘声明。

制作门槛：先按唯一规划city制作规格生成简化city-gray.glb，在目标画布验证区域完整可见、重点园区位于中右、3标签锚点投影与UI留白；再深化道路、水系、树木与城市体块。所有版本与B-city-v1并排对照，不修改确认图掩盖偏差。
