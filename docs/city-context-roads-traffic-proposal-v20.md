# v20 整体修正提案（待确认，尚未编码）

沿用已确认浅色B方案、区域轮廓、演示指标和城市→园区→A1路径。用户本轮要求：道路不能随意穿湖；城市不要像规则小格子；产业楼宇/配套服务应有交互；车辆需有轿车/SUV/货车与黑白红灰；缩远后外围不能大片空白。

## 当前事实

道路生成器对非桥梁仅检查小段中点是否在水中，没有对完整路面宽度与湖岸求交；局部路网由横纵等距线生成，边界处自然形成断头。区域点位INDUSTRY-DEMO和SERVICE-DEMO的action为null，当前原本是展示标签。园区车辆全部来自一个4.8×2米盒体模板加矩形驾驶舱，18辆共用外观。城市地形很大，但建筑路网只生成在原构图周边；固定6500米开始的雾在镜头拉远时会冲淡主体，外围也缺乏环境。

## 设计方案

1. 连续城市景深：重点区域保留完整表现；外围补低细节城区、连续绿地与水系，以合批体块提供中景而非复制中心园区。远景只保留城市轮廓并逐渐融入轻雾。覆盖现有允许的最大缩放范围，雾随观察距离调整，不能在缩远时把主体整体洗白。仍为概念城市，不能新增真实地名或测绘精度承诺。
2. 道路按用地组织：主干道串联片区，支路依街区和湖岸转向，减少横纵贯穿网格。普通道路按完整路面包络避让水体；明确规划的跨湖通道才作为桥梁，补桥台/栏杆，连接两岸。湖岸步道独立于车道；消除伸入湖面的小线头和无意义断路。
3. 两个点位改为可选对象：点击后选中标记和对应片区，轻缓移动镜头并打开同风格可关闭信息卡。产业楼宇展示现有产业方向/园区楼宇概况；配套服务展示现有会议、停车、通勤示范内容。再点另一个更新选择，Escape可关闭；不编造真实设施数量和经营统计，不新增楼层/房间层级。
4. 道路车辆：18辆数量和既有仿真时钟保留，建议9辆轿车、6辆SUV、3辆轻型货车，黑白红灰混合。车身有发动机盖、挡风玻璃、车顶和明确前后轮，使用圆轮胎；SUV更高，货车为独立驾驶室与货厢，避免平板AGV轮廓。保持真实米制尺寸、双向车道、转向与车速；按车型共享几何和材质，避免逐辆堆积独立对象。

## 执行与验收顺序

先做缩远的外围构图/路网与湖岸检查，确认无网格围栏感和穿湖，再细化地景；随后补点位反馈与车辆模板，最后三层联调。逐版保存默认、最大缩远与旋转视角，和原确认稿并排；验证点位切换、车辆外观/运动、对象选择、无数据态与12轮层级资源复验。主画面和UI保持既有清晰度，以LOD与合批控制成本。
