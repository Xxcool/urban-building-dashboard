# v15 窗口铺满专项修复

问题：固定1920×1080容器以min比例居中缩放，2048×951窗口两侧各留下约179像素空白。

修改：App.js从窗口尺寸派生等比缩放与扩展后的逻辑画布；侧栏采用基准设计宽度，剩余宽度交给场景。style.css的提示/声明锚点改用同一侧栏宽度变量。现有场景ResizeObserver更新渲染尺寸、相机纵横比，标签按宿主尺寸投影。未修改规划和模型，无需重新建模。

重建：在app执行npm run build成功。真实浏览器在2048×951分别覆盖城市、园区、楼宇，在1920×1080覆盖全部三层，并在1600×1000、1280×720复验园区。dashboard和canvas实际DOM边界与窗口贴合，误差小于0.01像素，无横向溢出。园区8标签、楼宇A1详情可见。

证据：checks/fullwidth-runtime-v15.json、checks/fullwidth-review-v15.html及其引用的八张截图。城市真实性R-05-REALISM保持开放，不以本次适配通过替代整体视觉验收。v14交付包保持历史内容，当前源码和dist已更新。
